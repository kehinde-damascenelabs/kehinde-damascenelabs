## Featured Work

**[Theo Prototype](https://github.com/kehinde-damascenelabs/ai-voice-agent_v0.1)**
An early browser-based prototype of Theo's real-time voice conversation loop:
WebRTC straight to the OpenAI Realtime API, live transcription, and
tool-calling for scheduling — built as the proof of concept before Theo
became a phone-based product.

**[openai_backend](https://github.com/kehinde-damascenelabs/openai_backend)**
The companion Express backend for the prototype above — mints Realtime API
session credentials, and exposes calendar and scheduling tools the voice
agent calls into during a conversation.
